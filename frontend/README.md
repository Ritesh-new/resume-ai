# Resume Builder Frontend

## Setup
```bash
npm install
npm run dev
```

Runs on `http://localhost:5173`

## Development

- Use Vite for fast HMR
- TypeScript for type safety
- Zustand for state management
- React Router for navigation
- Axios for API calls

## Build
```bash
npm run build
```

## Linting
```bash
npm run lint
```
